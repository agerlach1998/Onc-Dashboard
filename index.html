Import CSV
Two formats accepted: column CSV (Publish Date, Title, Author, Vertical, Specialty, Type, Status), or the team's weekly Daily Tracker CSV exported straight from the sheet. The parser auto-detects which one. Items like Title (Author) get split automatically.
How it merges: imported rows are marked as sheet-sourced. Anything you added by hand in the dashboard is kept. If you re-import the same file, sheet-sourced items are replaced (not duplicated).
Safety guard: if the file has less than half your current sheet-imported items, the import is refused and your data stays intact.
